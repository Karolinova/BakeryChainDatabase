# Excel vs Database

This file presents an analysis of the limitations of using Excel spreadsheets to manage data in a bakery chain business.

- It is difficult to monitor sales across all stores because data is not always consistent or up to date.
- There is no proper access control, which increases the risk of accidental changes to data.
- When multiple people work on the same file, it can lead to overwritten data and version conflicts.
- Sales reports need to be prepared manually, which takes time and increases the chance of mistakes.
